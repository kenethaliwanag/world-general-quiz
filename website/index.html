World General Knowledge Quiz

Short, educational quiz videos covering world geography, science, history, culture, sports, nature and technology. The project turns a curated question bank into narrated, vertical videos for an international audience.

How it works Read the Privacy Policy

What viewers can expect

  • Brief quizzes with an on-screen countdown and a clear answer reveal.
  • A mix of single-answer questions and comparisons, drawn from a wide range of topics.
  • English narration and readable subtitles in a vertical, mobile-friendly format.
  • Separate formats: a short-form quiz, a ten-question video and a full fifteen-question Part.

Question selection tracks previously used IDs so consecutive videos do not simply repeat the same questions.

How the project works

  1. A Part is assembled from the question bank, with topic and difficulty spread.
  2. A script, subtitle file and narration are generated for the selected questions.
  3. A vertical MP4 is rendered from the script and narration.
  4. A manually dispatched GitHub Actions job can upload the short-form video to YouTube as a private test using the YouTube Data API.

Public or scheduled YouTube publishing is not enabled. The automated publishing path currently available is a controlled, private test upload started by the repository owner.

About this website

This is a static informational site. It has no accounts, sign-in forms, advertising, analytics, tracking pixels or cookie collection. It explains the project and hosts the Privacy Policy and Terms of Service.

This site is intended for eventual use as the application home page and as the location of the privacy policy and terms for Google OAuth branding. Those Google branding steps have not been completed. World General Knowledge Quiz is not affiliated with or endorsed by Google or YouTube.
