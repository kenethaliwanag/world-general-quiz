# Product Roadmap

- [x] JSON question bank
- [x] Random unique selection
- [x] Persistent cross-Part history
- [x] Sequential Part numbering
- [x] TXT and JSON export

## Phase 2 — Audio and video
- [x] KokoroTTS HTTP integration
- [x] HyperFrames HTML composition generation
- [x] HyperFrames CLI render integration

- [ ] Add more verified questions and category-specific series
- [ ] Add a preview/review workflow before publishing
- [ ] Add configurable branding and multiple templates
- [ ] Add captions/subtitles and accessibility checks
- [ ] Add batch generation and job logs

## Phase 4 — Distribution and analytics
- [ ] Add Facebook publishing only through supported Meta APIs and permissions
- [ ] Add scheduled publishing and a content calendar
- [ ] Track views, watch time, comments and retention
- [ ] Use performance data to improve topics and hooks
